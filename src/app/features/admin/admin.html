Security Architecture & Privacy Guarantees

Zero Journal Exposure

Administrators manage platform users and system telemetry only. Individual user journals and reflection sessions remain strictly locked by owner-bound Firestore security rules (request.auth.uid == userId).

Dynamic RBAC Verification

Firestore rules enforce that only existing admins can execute elevated role updates (isAdmin()), preventing privilege escalation or self-elevation attacks.

Google Maps Attribution

All geospatial and reverse-geocoding calls comply with Google Maps Platform standards, using solution ID gmp_mcp_codeassist_v1_aistudio.
